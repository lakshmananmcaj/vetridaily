# VetriDaily — Feature Inventory

*As shipped in version 3 / 1.1.0 — the build that completed 14 days of closed testing.*
*Package `com.murugan.dailycalm`. Written 3 October 2026.*

Four tabs: **இன்று** (Today) · **கோவில்** (Temples) · **பண்டிகை** (Festivals) · **மேலும்** (More)

---

## 1. இன்று — Today

The daily practice. This is the product; everything else exists to give people a reason to
return after the journey ends.

| Feature | Detail |
|---|---|
| Daily affirmation | Tamil title and body, one per day, from Supabase `daily_content` |
| Narrated audio | Tamil TTS per day, generated by ElevenLabs, stitched with a common closing line |
| Audio controls | Play, pause, replay; stops and resets when the day changes |
| Progressive unlock | Day N unlocks on day N from the user's start date — the habit mechanic |
| Day navigation | Step back and forth within unlocked days |
| Journey completion | A proper completion screen when published content runs out, not an error |
| Error distinction | "No content for this day" is handled separately from "network failed" |
| Next Sashti countdown | Days remaining plus the muhurat window |
| Next festival countdown | Filtered to real festivals, never purchase-muhurat days |
| Daily reminder | Notification at a time the user sets |
| Share as image | Branded 1080×1920 card: circular logo, Tamil text, blessing, channel handle |
| Share to WhatsApp | Straight into WhatsApp or WhatsApp Business for Status |
| Send to a friend | Plain-text invite with the store link |
| YouTube handoff | One card after the audio controls, linking to the channel |

## 2. கோவில் — Temples

| Feature | Detail |
|---|---|
| அறுபடை வீடு | All six abodes of Murugan, numbered in traditional order |
| Wider directory | The other 24 temples, collapsed by default, alphabetical |
| Temple detail | Tamil name, deity in Tamil, significance in Tamil, description |
| Timings | Opening and closing times |
| Location | Location, city, district, state |
| Travel | Nearest railway station and nearest airport |
| Get Directions | Opens the temple's GPS coordinates in any map app, browser fallback |
| Read more | Links to the temple's page on informationneeds.com |

## 3. பண்டிகை — Festivals

| Feature | Detail |
|---|---|
| Year selector | Previous, current and next year |
| Month tabs | Tamil month names, opens on the current month and scrolls to it |
| முருகன் நாட்கள் | Skanda Sashti, monthly Sashti and Karthigai pinned above everything |
| பண்டிகைகள் | Festivals — Hindu, Muslim, Christian, Karthigai, Shivaratri and more |
| விரத நாட்கள் | Vratham days — Sashti, Ekadasi, Pradosham, Pournami, Amavasya, Ashtami, Navami |
| நல்ல நாள் | Auspicious days — muhurtham, property, vehicle, graha pravesham, girivalam, eclipses. Collapsed by default, since these outnumber the rest roughly two to one |
| Date format | Day number with the Tamil weekday, as Tamil calendars present a date |
| Muhurat windows | Start and end times shown on every row that has them |
| Festival detail | Tamil name, the next occurrence emphasised, up to 12 further dates, full description |
| Read more | Routes to the matching portal page — purchase muhurats go to their own page |

## 4. மேலும் — More

Nine portal destinations, grouped, plus the channel. Every tap is an ad-carrying page view on
informationneeds.com, which earns without any billing integration in the app.

| Group | Destinations |
|---|---|
| ஆன்மீகம் · Spiritual | Vratham days, Festivals, Today's panchangam |
| ஜோதிடம் · Astrology | Horoscope, Chandrashtama |
| நல்ல நாள் · Auspicious days | Property purchase, Vehicle purchase, Gold purchase, Starting a business |
| யூடியூப் · YouTube | @murugandevotee |

## 5. Notifications

| Notification | Behaviour |
|---|---|
| Daily reminder | At the user's chosen time, off by default |
| Festival and Sashti reminder | 7 PM the evening before, off by default, its own channel so it can be muted independently |

Scope is deliberately narrow — festivals and Sashti only, roughly 18 a year. Including Pournami,
Amavasai, Ekadasi and Pradosham would mean sixty-odd notifications annually, which is how an app
gets muted.

## Content sources

| Source | Supplies | Why |
|---|---|---|
| Supabase | Daily affirmations and audio URLs | Audio must be attached and playable offline |
| api.informationneeds.com | Festivals, temples, special dates | Live reference data, changes daily, no audio — read directly rather than copied, so no drift |

Festival and temple data updates on the website appear in the app without an app release.

## Technical

- Kotlin, Jetpack Compose, Material 3, MVVM
- Retrofit for both backends; WorkManager for reminders; MediaPlayer for audio
- `minSdk 23`, `targetSdk 36`
- 40 unit tests covering date filtering, section mapping, the Arupadai Veedu filter,
  the notification rule, caching and portal routing
- No ads, no in-app purchases, no analytics SDKs in 1.1.0
- Permissions: `INTERNET`, `POST_NOTIFICATIONS`

## Known gaps

Recorded honestly rather than omitted.

- **Sashti shows once a month, not twice.** The backend's tithi calculation samples once daily at
  6 AM IST and skips the தேய்பிறை (Krishna paksha) occurrence. A website fix, not an app fix —
  the app will show both as soon as the API returns both.
- **Three sources disagree** on September's Sashti date (festivals API, special-dates, and the
  owner's own list). Worth reconciling before people plan a vratham on it.
- **`FestivalReminderWorker` has never been observed firing.** It compiles and is covered by
  reasoning, not by execution; the first real run is on a festival eve.
- **No tests** for the HTML stripper or the share-card renderer — both need Robolectric.
- **Festival → video mapping** not built; deferred by the owner.
- **Subscribe prompt** not built.
